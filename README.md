# AI Football Predictor — Frontend

Live site: **[aifootballp.com](https://aifootballp.com)**

The frontend for an AI-powered football prediction platform, currently covering the **Premier League 2026–27** season and the **FIFA World Cup 2026**. It displays match predictions, title-race simulations, and model performance tracking generated by a backend prediction engine.

## What it does

- Displays match-by-match win/draw/loss predictions for the Premier League
- Shows live title race and league table simulations (10,000+ Monte Carlo runs)
- Tracks model accuracy against actual results as the season progresses
- Covered the FIFA World Cup 2026 with a full 48-team tournament simulation (65.9% overall match accuracy)

## Tech stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Deployment:** Vercel

## Architecture

This repository contains the frontend only. It consumes predictions from a separate backend service (FastAPI + Python) that handles data ingestion, model inference, and simulation. The prediction models, training pipelines, and historical datasets are maintained in a private repository, as they represent the core research and development work behind the platform.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally. You'll need to point `NEXT_PUBLIC_API_URL` (see `.env.example`) at a running instance of the backend, or mock the API responses for local UI development.
